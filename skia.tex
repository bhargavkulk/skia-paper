\section{Skia}

In this section, we introduce the basics of Skia's drawing API.
The next example demonstrates the API by drawing a rectangle.
All drawing happens into a canvas.\footnote{A canvas in Skia is represented by
an instance of a \texttt{SkCanvas} object, which owns all the drawing state.}

The drawing before the \texttt{Draw} command is an empty pixel buffer.
The drawing after the \texttt{Draw} command is a pixel buffer with a black square.
\texttt{Draw} needs two arguments: the geometry to be drawn and a \texttt{Paint}.

A \texttt{Paint} controls how a geometry is drawn.
For example, you can specify a fill color in a \texttt{Paint}.

Clipping can be scoped using \texttt{Save()} and \texttt{Restore()}.

% ------------------------
\begin{figure}[H]
\centering
% initial state
\begin{minipage}{0.3\textwidth}
\centering
\fbox{\includegraphics[width=\linewidth]{drawing0.pdf}}
\end{minipage}
\hfill
% command
\begin{minipage}{0.3\textwidth}
\scriptsize
\begin{BVerbatim}
Save();
  Clip(Rect(64,64,192,192), Intersect);
  Draw(Rect(0,0,128,128),
       Paint(Color((1,1,0,0)), ..., SrcOver));
Restore();
Draw(Rect(128,128,256,256),
     Paint(Color((1,0,0,1)), ..., SrcOver))
\end{BVerbatim}
\end{minipage}\hfill
% result
\begin{minipage}{0.3\textwidth}
\fbox{\includegraphics[width=\linewidth]{drawing11.pdf}}
\end{minipage}
\end{figure}
% ------------------------

Similarly, \texttt{SaveLayer()} pushes a new layer onto the stack.
Upon \texttt{Restore()}, the layer is drawn onto the layer below it,
according to the provided \texttt{Paint}.
