\section{Semantics}

\begin{figure}
  \begin{tabular}{S M c l}
    Image & i & : & \mathsf{Point} \to \mathsf{Color} \\[2pt]
    Shape & g & : & \mathsf{Point} \to \mathsf{bool} \\[2pt]
    Blend & b & : & \mathsf{Color} \times \mathsf{Color} \to \mathsf{Color}
  \end{tabular}
  \caption{
    Our abstract model consists of
    \textsf{Image}s and \textsf{Shape}s
    over abstract types \textsf{Pixel}s and \textsf{Color}s,
    which can be blended together
    to form images.
  }
  \label{fig:model}
\end{figure}

Our semantics of Skia is built around
  a simple abstract model of images and shapes,
  shown in \Cref{fig:model}.
- Abstract type of Pixels and Colors
- Image is Pixel -> Color
- Shape is Pixel -> Bool
- Blend is Color -> Color -> Color
Skia works by taking Shapes; filling them with primitive Images;
Blending the results together in various orders

However, Skia does not permit
  arbitrary drawing and blending operations;
  instead, these always happen in a prescribed order.
We thus introduce the Layer abstraction,
  shown in \Cref{fig:layer},
  which defines the core Draw and BlendLayer operations
  in Skia.
We focus on these two operations specifically
  because they are the core target of the optimizing compiler
  described in \Cref{sec:optimize}.
The Layer constructors can be defined in terms of the abstract model,
  as shown in \Cref{fig:denote}.
- Rename SaveLayer to BlendLayers(l, l, p)
- Define our 3 constructs in terms of primitive operations

As our main goal is to try and verify rewrites in Skia,
  it is hard to do so over \surface{}.
This is mainly because of the hidden layer and clip state of \surface{}.
That is why we introduce a new language called \core{},
  which is a declarative version of \surface{}.
\core{} makes layers the main value type of the language,
  and also make explicit the clip state at each draw command.
This also has the consequence of completely removing \texttt{Save}s from
  \core{}.

To verify rewrites in \core{} we define semantics for it.
We define a denotation function $\llbracket\;\cdot\;\rrbracket$ over \texttt{Layer}s.

\begin{equation*}
\llbracket \texttt{ Layer } \rrbracket : \mathsf{Point} \to \mathsf{Pixel}
\end{equation*}

That is,
  A \texttt{Layer} is a map from \textsf{Point}s to \textsf{Pixel}s,
  or more literally a buffer of pixels, indexed by points.
We now define the denotation function over the 3 types of \texttt{Layer}s.
First, the \texttt{Empty} layer.

\begin{equation*}
\llbracket \texttt{ Empty() } \rrbracket = \lambda pt . (0, 0, 0, 0)
\end{equation*}
