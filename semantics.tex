\section{Semantics}

As our main goal is to try and verify rewrites in Skia,
  it is hard to do so over \surface{}.
This is mainly because of the hidden layer and clip state of \surface{}.
That is why we introduce a new language called \core{},
  which is a declarative version of \surface{}.
\core{} makes layers the main value type of the language,
  and also make explicit the clip state at each draw command.
This also has the consequence of completely removing \texttt{Save}s from
  \core{}.

\begin{center}
  \begin{tabular}{S M c T}
    \core{} & s & ::= & $l$ \\
    \addlinespace[1pt]
    Layer & l & ::= & Empty() \\
          &   & |   & Draw($l$, $g$: \textsf{Geometry}, $p$: \textsf{Paint})\\
          &   & |   & SaveLayer($l$, $l$, $p$: \textsf{Paint})
  \end{tabular}
\end{center}

To verify rewrites in \core{} we define semantics for it.
We define a denotation function $\llbracket\;\cdot\;\rrbracket$ over \texttt{Layer}s.

\begin{equation*}
\llbracket \texttt{ Layer } \rrbracket : \mathsf{Point} \to \mathsf{Pixel}
\end{equation*}

That is,
  A \texttt{Layer} is a map from \textsf{Point}s to \textsf{Pixel}s,
  or more literally a buffer of pixels, indexed by points.
We now define the denotation function over the 3 types of \texttt{Layer}s.
First, the \texttt{Empty} layer.

\begin{equation*}
\llbracket \texttt{ Empty() } \rrbracket = \lambda pt . (0, 0, 0, 0)
\end{equation*}

Next, \texttt{Draw}.

\begin{equation*}
\llbracket \texttt{ Draw($l$, $g$, $p$, $c$) } \rrbracket =
\end{equation*}

\begin{BVerbatim}
    let l_b := denote l_b
    let (fill, blend_mode, style, filter) := paint
    let drawPx := if (style geo) pt && (clip pt)
                  then ((getFillFunc fill) pt)
                  else Pixel.Transparent
    blend_mode (l_b pt) (filter drawPx)
\end{BVerbatim}
